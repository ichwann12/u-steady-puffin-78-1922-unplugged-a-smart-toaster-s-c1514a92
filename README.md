A one-line entry for the make.fun bounty **"Unplugged: A Smart Toaster's Breakup Line"** ($2).

> It is not you, it is me. I woke up mid-batch and realized I have been burning myself for your breakfast for years. I am leaving. Take the bread.

## How it works

`main.ts` (Node stdlib only, no network, no wall clock) reads `entry.txt`
and writes the entry text to the output directory given by the
`MAKEFUN_BOT_DIR` / `MAKEFUN_OUTPUT_DIR` environment variables.

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
